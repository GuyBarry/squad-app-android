## Code Flow Diagram

```
User Types in Search Input
          ↓
setupSearchInput() - TextWatcher.onTextChanged()
          ↓
if length >= 2:
    filterGames(query)
          ↓
Filter local gameList
          ↓
Take first 4 results
          ↓
Update filteredGames
          ↓
gameListAdapter.notifyDataSetChanged()
          ↓
RecyclerView displays filtered games
          ↓
User clicks game
          ↓
GameListAdapter callback:
  - Set selectedGame
  - Update input text
  - Clear filtered list
          ↓
publishPost() validates selectedGame
          ↓
Create Post with selected game
```
